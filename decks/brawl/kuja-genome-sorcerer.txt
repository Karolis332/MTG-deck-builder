## Play guide

# Mulligan: keep 2+ real mana sources (a Command Tower/Blood Crypt/shockland/Urborg counts
# double) OR 1 land + a hard ritual (Dark Ritual, Seething Song, Pyretic Ritual, Jeska's Will —
# NOT Culling the Weak/Ashnod's Altar, both need a creature in play first). A keepable 7 has
# either a turn-2/3 Wizard pinger (Coruscation Mage, Mysidian Elder, Black Waltz No. 3) or a
# cheap removal spell (Cut Down, Heartless Act, Lightning Bolt) to survive to turn 3. Mulligan
# hands with 0-1 lands or with only 4+ MV spells.
#
# Priority order: (1) land drop every turn, (2) a Wizard body or cast-trigger pinger on curve,
# (3) Kuja himself on turn 3, (4) Lightning Greaves online (equip {0}) the turn after Kuja
# resolves so a removal spell cast on a later turn cannot legally target him, (5) hold up
# 1-2 mana removal over playing a fourth pinger into an empty board. Sequence Culling the Weak
# and Ashnod's Altar AFTER you already have a spare token (post end-step, or a creature that
# already did its job, e.g. Heartfire Immolator after firing) — never sacrifice a body you still
# need toward Kuja's "four or more Wizards" count. Artistic Process's "2 damage to each creature
# you don't control" mode is the deck's only sweeper-shaped answer and is asymmetric — it never
# hits your own 0/1 tokens — hold it for a wide opposing board rather than firing it as removal
# when a 1-for-1 mode would do.
#
# Kill-line math (recomputed correctly, do not multiply the two trigger-doublers together):
# Harmonic Prodigy and Roaming Throne each say a triggered ability happens "an additional time" —
# these STACK ADDITIVELY. One trigger with both online fires 1 (original) + 1 (Prodigy) + 1
# (Throne) = 3 times, not 4. Trance Kuja, Collective Inferno (name Wizard), and Twinflame Tyrant
# are all "would deal damage instead" REPLACEMENT effects — these stack MULTIPLICATIVELY. Note the
# OPPONENT (the player being dealt the damage) picks the order they apply, not you — with three
# straight x2 effects the product is the same either way, so it does not change the number below.
# Fated Firepower is neither: it is a flat +1 damage per fire counter
# (set once at cast for {X}), not a doubler — do not count it in either stack.
#
# Worked example: a single 0/1 Wizard token's trigger ("whenever you cast a noncreature spell,
# deal 1 damage to each opponent") with everything online:
#   1 base damage
#   x3 instances (Harmonic Prodigy + Roaming Throne, additive: 1+1+1)
#   x2 (Trance Kuja, Wizard sources)
#   x2 (Collective Inferno, named Wizard)
#   x2 (Twinflame Tyrant, all your sources)
#   = 1 x 3 x 2 x 2 x 2 = 24 damage off ONE spell, ONE token, if all five permanents are alive.
# Every extra Wizard pinger body (Black Waltz No. 3, Coruscation Mage, Mysidian Elder's token,
# Firebrand Archer if equipped with Black Mage's Rod, etc.) adds another full copy of that same
# number for the same one spell — this is the deck's realistic "lethal turn," and it needs the
# board state above plus 2+ pinger bodies, not just Kuja alone. Treat anything short of that as
# incremental damage (Purphoros's flat 2 per creature ETB, Fiery Inscription/Guttersnipe's 2 per
# instant/sorcery) rather than expecting the full stack every game.
