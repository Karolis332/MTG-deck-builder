Paper deck library lives at `C:\Users\QuLeR\Desktop\MTG decks\`.

Convention: `<commander-or-archetype>.txt`, one card per line as `<count> <card name>`, comments with `//`. README.md in the folder defines the format. Importable to Moxfield / Archidekt / Arena.

When asked to save, modify, or look up a paper deck, use this folder — not `C:\Users\QuLeR\MTG-deck-builder\decks\` (which doesn't exist).

**Paper card inventory:** `_my collection.txt` in the same folder is the running list of cards owned. Append new card names mentioned in chat (alphabetized, deduplicated). Started 2026-05-04.
